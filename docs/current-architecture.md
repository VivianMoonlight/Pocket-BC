# 当前架构

本文维护当前实现的职责、状态所有权和关键约束。构建入口见 [README](../README.md)，持久化格式与迁移契约见 [存储架构](storage-architecture.md)。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `app` | Android 入口、前台服务、依赖装配、导航、通知和资源访问 |
| `core:model`、`core:protocol` | 跨层值对象、协议模型与编解码 |
| `core:socket` | BC 协议适配、socket 状态归约和实际发包校验；依赖领域契约，并非通用网络库 |
| `core:ui` | 共享主题、组件、窗口 inset 和转场 |
| `domain:*` | 会话、消息、发送恢复、角色规则及文本资源业务 |
| `data:storage` | Room/DataStore 实现与领域存储端口适配 |
| `feature:*` | 页面展示状态、用户意图及 Compose 界面 |

实际模块与依赖以 `settings.gradle.kts` 和各模块构建脚本为准。扩展功能优先接入已有领域能力，避免为同一操作增加平行 facade 或状态源。

## 状态与生命周期

| 状态 | 所有者 | 生命周期 |
| --- | --- | --- |
| 活跃账号、连接与房间 | `BcSessionForegroundService` → `AccountSessionManager` → `DefaultBcSessionRuntime` | 由服务管理；页面只通过 `SessionAccess` 使用同一 runtime |
| 当前路由、返回栈与转场方向 | `AppNavigationState` | 单次发布同一个不可变快照，ViewModel 只投影；通过 `SavedStateHandle` 恢复路由和返回栈，账号切换重置导航 |
| 页面模型与共享草稿 | `SessionFeatureSet` | 同一会话附件复用；真实解绑或宿主 ViewModel 清除时释放 |
| 聊天/角色资料页面模型引用 | `ScreenModelOwners` | 最后一个页面退出后延迟释放，允许同帧转场接管；释放回调绑定原 feature graph |
| 聊天可见性与已读观察 | `ChatViewModel` | 每个可见且 STARTED 的页面实例持有独立 owner；旧页面只能撤销自己的可见性 |
| 草稿与待完成发送 | session 内按会话保存的 `ChatInputState` 与发送 scope | 页面退出不取消提交；账号切换或退出清理输入，不保证进程死亡恢复 |
| 接受好友请求与反馈 | `ConversationsViewModel` 的带归属请求状态 | 请求对象同时提供接受目标与重复点击门禁；跨登录请求互不占用，迟到结果按请求身份更新或释放 |
| 角色关系操作与反馈 | `CharacterProfileViewModel` 的带归属请求状态 | 请求标记同时负责重复点击门禁与忙碌投影；账号或代次变化后忽略旧提示，旧完成回调只能释放自身请求 |
| 房间互动对象、参数及执行反馈 | `RoomDetailsViewModel` | 共享房间上下文；互动与自身修改的忙碌状态从已登记任务派生，取消先解除归属；宿主导航关闭离开的互动，聊天页只清理自身临时状态 |
| 进程内重连账号与密码 | `BcSessionRuntimeState.rememberedLogin` | 账号与密码作为不可变凭据统一替换；重连读取完整快照，强制断线只清除密码，退出清除整体 |
| 进程内重进房间目标 | `BcSessionRuntimeState.rememberedRoomTarget` | 房间名与密码是不可变整体，只能统一替换；自动重进读取一次完整目标，持久化仍只保存房间名 |
| 消息、已读游标和 outbox | Room | 持久化事务及按账号查询是权威来源 |
| 会话列表投影和当前可见会话 | `BcSessionTimelineController` | 合并存储结果与在线状态，仅暴露只读列表；账号或 generation 改变时清理旧投影和选择 |
| 登录页、个人页保存账号与系统版本 | 存储层 `observeLoginState()` → `SessionFeatureSet.savedLoginState` | 两页与外壳订阅同一派生流，无手动重读刷新；登录页仅拥有已编辑字段、菜单和操作反馈 |
| 通知偏好与文本还原开关 | 服务持有的设置存储 | SharedPreferences 变更发布只读状态流，设置页、通知策略及文本解析读取同一来源；服务销毁时注销监听 |
| 动作、规则及背景目录使用的版本 | 会话版本与已确认保存配置的派生流 | 会话版本优先；仅缺失时使用保存配置，不由登录回调另行赋值，无效会话版本不退回另一版本 |
| 房间发现页 | `RoomsViewModel` 只拥有搜索草稿、结果与本地操作状态 | 在线状态和当前房间来自同一 session snapshot，管理表单来自表单控制器；统一投影生成 UI，命令门禁读取原始操作状态 |

AccountSessionManager 的普通停止允许后续重新创建会话；服务销毁时永久关闭管理器。关闭与会话发布共用同步保护，等待中的账号切换不能在关闭后发布新会话。

Activity 配置重建时暂停 binding 观察并复用原 feature graph。模型释放与可见性是两件事：Pager 预加载页面可以持有模型，但不能因此推进已读。

应用外壳直接由 binding 就绪、当前账号和可恢复账号数量推导；聊天是否活跃直接由可见 owner 集合推导，不另存可独立修改的状态标志。

账号观察流在存储层互斥读取账号元数据与凭据；账号写入会通知观察者，即使只改密码且 DataStore 元数据未变。可恢复账号数量从同一快照派生。读取失败时发布不可恢复的错误状态并重试，不继续使用旧账号缓存。

登录表单的未编辑字段直接从保存账号快照推导；用户修改的字段由本地草稿覆盖。编辑密码或服务器时固定草稿账号，默认账号变化不能把输入移到另一账号。选中保存账号时按账号名重新读取凭据，删除及登录也重新读取来源，不依赖可能滞后的 UI 投影。

自动重进房间的当前生效值由 session snapshot 唯一提供。设置操作先更新运行时，再保存下次启动配置；保存失败保留当前生效值并显示警告。页面不能用请求值或保存完成事件覆盖会话投影。

设置页只提交通知和文本开关修改，不持有已生效设置的可写副本。设置存储读回 SharedPreferences 内存值后发布，沿用 `apply()` 的异步落盘语义，不把状态流更新当作磁盘持久化确认。

相互依赖的展示字段从同一次 `BcSessionSnapshot` 投影。个人页日志列表与总数来自同一次日志快照；登录页、个人页和房间发现页用原子更新发布投影，遇到竞争时重新读取来源，防止旧投影覆盖新结果。异步结果必须复核账号 generation、登录 UUID、房间访问 epoch 和请求目标，不能用旧结果更新新上下文。

认证控制器只改变认证状态，不直接写入会话列表或可见会话。时间线控制器在账号观察和在线状态写入前统一检查归属，防止新账号查询尚未返回时混入旧列表；普通断线仍保留当前账号历史。

会话列表以 `BcConversationSnapshot` 连同账号号码和 generation 一起发布。会话列表页与聊天页只使用匹配当前 session 的行数据；账号快照先于列表更新时显示空列表或默认标题，不给旧数据重新标记账号归属。角色历史资料同样以 `BcContactProfileSnapshot` 携带查询账号与登录代次；资料页只采用与当前会话匹配的资料和最后出现时间。

时间线不改写 Room 查询缓存。断线、离房和改名的状态说明在展示时合并，重入房间或账号变化时清理；未读数、静音和已有会话的更新时间继续来自持久化结果。状态写入失败时保留独立错误提示，不能把实时连接状态误当成已保存成功。

## 导航与交互

- 主界面为房间、会话、设置三个 Pager 页面，底部导航与滑动使用同一目标路由。主页面切换替换根路由，不累计返回栈。
- 房间页在有活跃房间时展示当前房间时间线，否则展示房间发现。在房间内主动浏览其他房间属于详情路径，返回仍可回当前房间。
- 角色资料、独立聊天、房间详情和主动登录表单保留入口返回路径。返回会话或设置根页后，再返回到房间根页；Back 不执行离房。
- Pager 的请求目标属于导航，已落定页面属于转场状态；滑动取消保留原页面临时状态，完成切页后由宿主关闭房间互动。
- 成员抽屉只服务当前房间页，关闭动画后的操作复核账号、房间访问和成员仍在场。
- 聊天页拥有选择、菜单、滚动和焦点；关闭共享互动由宿主导航或明确用户操作发起，退出动画中的旧页面不能清理新页面的互动。
- 房间改名更新路由、返回栈和可迁移草稿；离房清理对应详情返回入口。历史消息、已读游标和 outbox 尚未实现完整重命名迁移。

## 消息与发送边界

消息与房间私语观察统一发布 `BcMessageSnapshot`，账号和登录代次由查询源头确定。聊天页合并消息前核对真实归属，旧快照不能被重新标记为当前登录数据，也不能推进当前页面的已读。已读命令继续携带消息批次的账号及代次，时间线控制器在接受写入时校验；不以执行时的当前账号替换请求归属。

入站路径为 socket 冻结接收账号/房间 → 有序处理 → 文本解析 → 存储事务 → 时间线及通知。服务端 MsgId 用于去重；缺失 MsgId 时使用接收 occurrence，不能按相同文本去重。

公开消息属于房间会话。Whisper 和 AccountBeep 可属于同一个成员会话，但发送条件不同：Whisper 必须同房，Beep 是账号级传输。模式失效时保留草稿与意图，不自动降级为公开消息或另一种传输。

房间时间线只读投影当前账号、来源房间明确匹配的 RoomWhisper，保留原消息与会话 ID，不复制消息或通知。房间投影不推进 direct 累计已读游标，避免把未展示的 Beep 标为已读；因此已在房间看过的私语仍可能在个人会话显示未读。

公开和各私语目标分别保存草稿与回复。发送完成只清理原提交对应的输入；迟到结果不能清除后来输入。Room Chat/Emote/Whisper 使用 2000 UTF-16 长度限制。

outbox 在入队、出队和实际 emit 边界检查归属及权限。私语带本地来源房间；旧普通私语缺失来源时失败并保留，不猜测当前房间。已经发包但缺少 echo 的消息超时后显示失败，不自动重发；迟到 echo 仍可确认。

数据库临时写入失败可取消地重试。session 关闭时未保存入站帧移交进程级持久化队列，该队列不继续操作 session；进程终止前未提交的帧不能保证恢复。持久化错误独立于连接错误显示，并绑定账号及具体操作。

## 角色与房间操作

角色候选来自目标版本目录及编译期 Echo 快照，经过统一权限投影和 `BcCharacterInteractions` 执行。保留完整 Property、锁与独立元数据；未知脚本能力不能用空属性覆盖来伪装支持。UI 禁用不能替代领域和最终 emit 校验。

原生 `ChatRoomCharacterItemUpdate` 不会把单件更新回传给发送者。发送流程在最终状态校验内完成实际 emit，成功后将同一份发送属性应用到本地房间快照，触发角色及立绘刷新；目标为自己时合并保存账号外观。发送失败或状态校验拒绝时不修改本地外观，也不广播动作文字。本地应用是发送者的原生客户端行为，不是服务器确认；后续收到的角色或物品同步仍可覆盖它。AFC 使用实际发出的锁身份和属性更新本地快照。

原生与 Echo 道具／服装的展示名称由 `parseBcItemNames` 统一合并，聊天字典和物品目录共用相同的翻译、空名称回退、旧名及镜像槽位规则。原生 CSV 的同组同名重复项取首条，Echo 延续既有覆盖顺序；物品目录在合并完成后统一排序。展示目录不授予穿戴或配置能力，操作候选仍取自规则目录。穿戴与替换共用候选筛选和分页，替换排除当前物品，各自保留权限判定与状态提示。

规则与文本抓源保留完整的正式版／Alpha／Beta 版本号，按版本和源地址隔离快照。资产文件优先使用该版本的已知目录布局，仅在 HTTP 404／410 时尝试同版本的另一种已知布局；本地缓存路径保持稳定。不同版本、文件、端口或查询参数的重定向不能作为原请求的成功结果，完整下载仅接受 HTTP 200，单次网络调用限制为 60 秒。权限错误、服务器错误、HTML 和空响应不会触发目录回退；抓取失败不发布暂存文件，也不覆盖原有完整快照。更换源地址后，旧源快照不能被当作新源已就绪。此路径兼容不等于支持未知版本的脚本语法，规则解析仍须通过目录健康检查。

角色资料页提供 R133 静态立绘预览，也可显示保存的历史外观。当前房间已验证在线后，应用在前台逐个预渲染成员当前外观，下载所需图层并持久保存完整帧；打开预览时优先使用匹配账号、外观和渲染版本的帧。外观变化、离房、断线或切换账号会更新或停止预热；预热尚未完成、图片缺失或网络失败时仍可能等待，部分帧不作为完整帧保存。预热与预览 WebView 只接收绘制所需的外观、颜色、物品属性和姿势，不接收账号原始数据，也不拥有 session 或角色操作权限。

立绘显示使用设备本地统一开关，首次默认隐藏，隐藏后跨重启保持；按住聊天记录旁的裙子与状态图标可展开滑块，提示气泡跟随拖动，拖到底后显示立绘，单击隐藏立即生效。资料页使用同样的图标与行为。动作与道具面板共用身体部位区域，动作部位按规则中的镜像映射查找对应动作；立绘显示在区域下方，加载或隐藏时仍使用同一操作区域，并提供部位列表。面板可以展开为全屏，在部位提示及其下方的内容区域左右拖动切换房间成员，内容跟随手指移动，顶部姓名和功能条保持固定；也可以点选顶部姓名，姓名放得下时居中排列，放不下时循环滚动并以分隔线标记首尾。布局模式选中部位后隐藏视图切换和搜索栏，功能条的部位名称可返回部位选择；列表模式保留筛选菜单，动作以双列排列，不可用动作开关位于列表末尾。完整帧旁保存同一绘制版本及外观的几何数据；几何尚未加载时使用默认身体坐标，加载后按实际翻转调整。隐藏不停止后台预热。

立绘支持旧版 LSCG 按图层序号保存的绝对位置，按 BeforeDraw 的优先级覆盖最终坐标，保留姿势偏移及已有绘制回调。R133 道具级与图层级的相对位移、缩放、旋转、镜像、倒置及遮罩，在二维路径中对照固定版本的 WebGL 绘制；包括该版本在 CommonDraw 和 GLDraw 中分别应用位移的行为。立绘使用原始人物画布，去除房间高度造成的整体缩放与上下偏移，保持统一尺寸；道具自身的绘制偏移和缩放仍然保留。渲染输入变化会使旧帧失效。

绘制运行时复用固定清单的官方 R133 脚本，下载后核对 SHA-256；`Game.js`、`Server.js` 和 `Import.js` 不加载。脚本、图片和少量素材文本通过专用 HTTPS 虚拟源访问，只允许清单中的脚本与指定资源路径，使用独立的有限磁盘缓存。若上游修改了固定脚本，必须重新验证后更新清单，不能绕过校验。其他 BC 版本不支持。未收录物品或无法独立运行的动态绘制只跳过对应物品，返回 `partial` 和缺失名称；全部没有可见图层时仍显示不支持。图片加载失败或等待超过 90 秒时沿用 BC 的逐层跳过，显示可用图层并返回 `partial` 和缺图数量，不删除整个道具或永久停用绘制。原生 UI 在立绘下方用小字提示。后续外观快照清理上一帧图片状态并重新尝试；超时后迟到的图片不主动更新已经完成的预览。单次绘制异常返回 `failed`，下一份有效快照可以恢复；核心脚本或初始化失败则需要重建 WebView。

带 `ScriptDraw` 标记但仅含普通图片层的物品可以静态显示，始终保持 `RunScripts=false`。同时具有 BeforeDraw/AfterDraw 动态回调的物品需单独审查，当前只额外允许能独立初始化第零帧的 `Wings/SteampunkWings`。不启动动画循环、不调用 ScriptDraw，也不引入角色更新或网络接口。浏览器回归以抛错哨兵检查 ScriptDraw、ServerSend、ChatRoomCharacterUpdate 未被调用，并验证静止帧、输入快照不变、部分预览恢复和纯未知外观清屏。Echo 的贴贴、抓住推车等六个不可见互动标记保留资产身份，不执行其交互钩子，也不阻止单人立绘显示。

Echo 立绘兼容内置 `echo-clothing-ext@4478e33044a6d87a4d1b0c6ed8d38a549e1d4204` 数据包，默认直接查询 Echo GitHub 固定提交，并在本地静态提取兼容数据；未变的复杂定义通过源码与依赖哈希复用审核结果。可选的 HTTPS 数据包清单仍可通过构建属性覆盖。目录、名称和图片哈希按进程固定，新下载包下次启动生效；行为适配仍由 APK 提供。发布和回退约定见 [Echo 数据包更新](echo-data-updates.md)。`portrait/echo.js` 注册已收录服饰、头发和 24 个叠加槽位，保留颜色、TypeRecord、姿势映射和手臂遮罩，并兼容快照中的旧物品名。JSON 由 `scripts/generate-echo-portrait.mjs` 从核对过 Git blob 的源码提取，生成器拒绝未知依赖与运行时回调；特殊授权条目不纳入该快照，归属和许可保存在 `portrait/echo/`。Echo 图片按固定提交、精确文件白名单读取并验证 Git blob，中文路径只解码一次；不接收可执行的远程 Echo 脚本。图片别名加载完成后显式重建角色画布，避免 BC 缓存按原路径找不到角色而漏绘。此兼容仅覆盖收录的静态外观，不代表完整 Echo/LSCG、Echo 全局原版贴图替换、动画或双人互动场景支持。真实 Android WebView、在线外观及生命周期仍需设备验证。

多类型、多模块外观沿用官方 R133 对 `TypeRecord`、`AllowTypes` 和 `CreateLayerTypes` 的解释。Echo 提取器支持纯 `ExtendedTools` 左右／双侧配置与多模块常量，并按 BC 槽位继承的 `DynamicGroupName` 校验和收录图片，避免发饰因实际图片位于 `HairAccessory1` 而被误排除。已收录武器组合的类型／收起拔出、独立纹身模块和左右配件；缺少的类型键只在绘制副本中补为选项 0，保留收到的其他属性，不推导或发送道具操作。浏览器回归覆盖武器的 16 种组合、条件手臂遮罩、姿势、缺省模块、重复切换、叠加槽位、多道具共存及移除后的清屏恢复。

房间创建、更新和成员管理与聊天 outbox 分开；缺少请求 ID 的响应通道在超时、取消或结果未知后隔离，不能把迟到回包当作新请求结果。房间状态以权威 Sync/Properties 为准，单独 ACK 不替代状态同步。基本设置更新保留未编辑的原始字段，避免覆盖未知设置。

衣橱保存、命名和恢复复核预览源、账号、登录、房间、版本及 revision。请求已发送、外观匹配和账号持久化成功是不同结果；当前外观观察不证明重新登录后仍已保存。

## 已知边界与验证

`portrait/supplement/` 是随 APK 发布的立绘脚本兼容补充包。清单绑定 BC 版本、Echo 提交、源码哈希和具体道具，提取器只为已登记的回调输出适配 ID，运行时将它绑定到本地 BeforeDraw 函数。当前移植白大褂和呢子大衣的伪装绘制逻辑、白色礼服的悬挂姿势绘制逻辑，并管理机械翅膀的静止首帧许可。提取器允许同一组件包含适配资产与普通静态资产，写入前与运行时共用包版本及绑定完整性检查。叠加槽位沿用相同扩展配置；不运行 ScriptDraw、不注册交互事件、不修改原生快照。版本不符、绑定错误或未登记回调均不能静默接入。维护步骤及来源归属见包内 README，验证包括上游函数对照与浏览器实际绘制。

- 地图距离与部分私有游戏输入、owner 物品/项圈副作用、Unban/白名单及高级房间管理仍有覆盖缺口。
- 没有独立 Emoji 面板、手动重发或 Lock/Unlock；历史消息自动重翻译尚未实现。
- 当前发送路径停用本地 BabyTalk/GagGarble/Stutter 及说话效果门限，保留 OOC 偏好与适用 OwnerRule。保留的言语算法对照测试限定 R129，不代表所有 BC 版本兼容。
- 双账号关系变化、费用、多人并发管理、衣橱重新登录持久化和通知/服务生命周期需要在线或设备验证，单元测试不能替代。

代码修改执行 `./gradlew.bat testDebugUnitTest assembleDebug`。测试报告在各模块 `build/reports/tests`，Debug APK 在 `app/build/outputs/apk/debug/`。每次交付报告本次实际验证结果，不在架构文档中维护过时的测试计数或设备状态。

持久化失败由时间线控制器唯一维护，失败对象保留账号号码和登录代次；列表页与聊天页只展示属于当前 session 的失败，避免同账号重新登录后短暂显示旧错误。
